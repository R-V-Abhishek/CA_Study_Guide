# Phase 5 verification

Observed 5 October 2026. Phase 5 adds experimental classification and authenticated, revision-safe review mechanisms. **It does not approve the live corpus.** The Phase 4 figures of 181 candidate extraction revisions, 2,909 assembled roots and 7,262 parts remain parser-output counts. Taxonomy, metadata, extraction-quality and source-coverage gates remain open.

## Classification and reproducibility

`uv run caf classify export --taxonomy textbook-v1 --revision ID --draft --output batch.json` reads explicitly selected immutable extraction snapshots. It exports the complete root question, shared context, ordered parts, available answers and answer status. Candidate evidence contains taxonomy paths, definitions, exclusions, descriptor revision IDs/hashes and textbook references. P1–P5 retain paper boundaries; IBS permits cross-paper candidates.

`uv run caf classify operator-run --batch batch.json --output-dir results --workers 4` executes the requested `gpt-6-luna` through the installed Codex CLI, outside HTTP requests, in an isolated temporary directory with read-only permissions and a restricted environment. It ignores user configuration and receives no database credentials or publication tools. Structured outputs require explicit `matched`, `needs_review` or `none_fits` outcomes, complete part coverage and support for every selected label. Atomic result/state writes, per-root jobs, reconciliation from validated completions and an exclusive coordinator lock support interruption recovery. Per-attempt response/schema/event files retain failures during retries. A failure is distinct from an unresolved classification, and no provider switch supplies replacement results. The [official non-interactive Codex documentation](https://learn.chatgpt.com/docs/non-interactive-mode) describes the structured-output execution interface.

`uv run caf classify import --batch batch.json --output-dir results` validates root IDs, part IDs, paper scope, candidate membership, extraction/content/descriptor/source hashes and every completed mapping before appending immutable suggestions. Repeated imports retain the same evidence. A changed input or classifier configuration requires a new batch; `--run-label` on export permits an explicit same-configuration rerun without overwriting earlier evidence. Experimental suggestions cannot publish or contribute topic-verification counts. Phrase anchors retrieve candidates; ambiguous matches remain unresolved instead of receiving every matching descriptor as a label. Gemini remains an explicit existing classifier option.

The frozen artifacts in `artifacts/phase5/` contain the sample, batch manifests, independent labels and model execution evidence. The sample contains **120 roots, 20 per paper**, split into 60 development and 60 holdout roots. Normalized duplicate groups contribute one sampled occurrence and stay in one partition. The pilot contains 12 roots, two per paper; the independent comparison contains 30 roots, five per paper. Independent labels were frozen before inspecting Luna outputs. They are agent judgments with unrecorded exact agent model identity, not student adjudication or ground truth.

## Review and publication

Migration `0006_classification_revisions` adds suggestion revisions, classification revisions, current root-publication pointers, immutable request/review events, per-account revision verifications and disputes. Database triggers reject edits or deletion of suggestion/classification/event history. Unique constraints enforce import identity, mutation idempotency and one verification record per account/revision. Withdrawals retain events and the original verification record.

Publication requires an active authenticated account, complete root mapping, pinned current extraction and its actual quality reviews, confirmed current Final source metadata/provenance, and reviewed taxonomy/descriptor/source evidence. A reviewed missing answer can remain explicitly absent. Model confidence never grants readiness or publication. The initial reviewer verifies the published mapping once; another confirmation of identical material verifies that same revision. Changed labels, content or taxonomy evidence require a new reviewed revision and fresh verification. Model reruns preserve existing publication and verification history.

Mutations lock the publication and check expected suggestion/publication revisions within the transaction. Source and taxonomy locks serialize publication with metadata changes, extraction promotion and descriptor edits. Stale requests return structured `409` responses with the current publication ID; readiness failures return structured `422` blockers. Idempotency keys are bound to the authenticated account and exact mutation request. Bulk publication is administrator-only and receives explicitly selected revisions with the same checks in one transaction.

Corrections and disputes retain the previous publication. A replacement needs an explicit full review; open disagreement requires an administrator's recorded resolution reason. Exclusion and `none_fits` retain distinct mapping states and never manufacture labels. Dated eligible parts update existing appearance/tag projections transactionally with classification revision references. Undated collections retain the root publication and record a deferred legacy appearance projection instead of inventing an attempt.

## Curator workspace and historical compatibility

`/curator/classifications` shows the whole question and complete available answer, pinned candidates with full topic paths, provenance, uncalibrated confidence, readiness blockers, current published content/mapping, distinct-student verification count, history and correction differences. Filters cover paper, source, outcome, taxonomy, experimental status, readiness and disputes. Blind benchmark mode hides recommendations until submission; draft annotations remain pending evidence without publication or verification. Topic-label verification is explicitly separate from extraction-quality review. `/curator/bulk` requires selected revision IDs and complete-review confirmation.

OpenAPI and the shared TypeScript client contain the same contracts. Historical suggestions in the original queue are selected coherently from one run/method/model/prompt configuration. Their verification state remains unknown. New historical HTTP acceptance and automatic bucket publication return `revision_review_required`; the historical automatic-bucket CLI/service also rejects publication. Retained decisions and appearances are unchanged. The read-only [legacy audit](Phase5_Legacy_Audit.json) flags 1,429 existing suggestions for missing revision evidence or uncalibrated support and identifies questionable accepted labels without manufacturing bindings or identities.

Evaluation pairs a frozen suggestion with a blind review of the same input and taxonomy. Duplicate content groups are counted once. It reports label accuracy, multi-label precision/recall, unresolved outcomes and candidate-retrieval misses with paper/source/bucket sample sizes. The configurable Bucket A threshold defaults to 80%, with at least 30 independent adjudicated root examples required for calibration. Draft or agent-comparison evidence stays provisional, and no evaluation score authorizes publication.

## Completed Luna experiment

The 12-root pilot and all **120 sample roots / 734 attributed parts** completed using `gpt-6-luna`. The sample reused validated pilot outputs rather than repeating those calls. Its outcomes are 469 `matched`, 79 `needs_review` and 186 `none_fits` parts. Import run 148 appended 120 experimental suggestion revisions; repeat run 149 appended **zero**. The [live import audit](../artifacts/phase5/import-verification.json) compared every stored complete context, answer, candidate set and part mapping against its frozen input and validated output. No current extraction, existing decision, published appearance or student verification was changed by these imports.

The [provisional comparison](../artifacts/phase5/comparison.json) covers the fixed 30 roots, five per paper, and 241 parts. The independent agent supplied primary labels for 27 parts; 18 agreed with Luna (**66.7% primary-label agreement**). Micro multi-label precision is **13.9%**, recall **72.2%**, exact part label-set agreement **43.6%**, and outcome agreement **25.3%**. Paper, source/bucket and development/holdout breakdowns are retained in the report. These values compare models on draft inputs; they are not estimates of student-adjudicated accuracy.

The independently recorded notes identify swallowed whole papers, answer/option fragments treated as gradable roots, incomplete shared cases and missing candidate concepts. Luna often assigned labels to those fragments while the independent agent left them unresolved. Zero measured candidate-retrieval misses does not certify coverage: missing concepts in this comparison remain unresolved instead of receiving unsupported labels. Independent student adjudication and improved extraction/taxonomy evidence are required before calibration. Still-unresolved independent labels do not supply calibration evidence. Only nine distinct Bucket A roots have resolved independent comparison labels, with provisional agreement of 16/22 labeled parts; **Bucket A is not calibrated**.

Successful persisted calls recorded 6,182,121 input tokens and 166,444 output tokens, including 33,550 reported reasoning-output tokens. Median successful root latency was 18.75 seconds; summed successful call latency was 3,695.949 seconds across parallel jobs, not elapsed wall time. Independent-agent token usage and model-call latency were unavailable. Nine failed attempts across the initial pilot, pilot retries and sample were kept separate: seven validation failures and two observed capacity failures. Early failure histories precede per-attempt response archival; usage totals cover successful persisted calls only. Identifier enums and output completeness constraints repaired response transcription/schema errors without changing label instructions, the frozen roots or development/holdout allocation.

The [coverage inventory](../artifacts/phase5/coverage.json) records 2,498 available unique roots across 111 strata, including 16 available but unsampled strata. Genuine mock/model question snapshots were unavailable for every paper in this selected extraction inventory. Other paper/source gaps are listed explicitly. The original [sample](../artifacts/phase5/sample.json), [batch](../artifacts/phase5/sample120.json), [independent labels](../artifacts/phase5/independent30_labels.json) and execution directories preserve the inputs and results.
