# CA Final Study Companion

An offline-first study companion and historical exam intelligence platform for CA Final preparation.

## Quickstart

### Prerequisites
- Python 3.12+ (managed with `uv`)
- PostgreSQL 16 (via Docker or local Homebrew service)
- Node.js LTS (for web frontend)

### Environment Setup
```bash
cp .env.example .env
uv sync
```

### CLI
```bash
caf --help
caf status
```
